使用说明

如何连接青龙？

在本页青龙面板区域填写 HTTPS 地址、Client ID 与 Client Secret。先在青龙应用设置授予环境变量权限。保存不会连接面板，实际抓取时由 QX 直接认证与同步。

为什么没有触发同步？

确认已导入当前应用的独立重写，启用 MitM 并信任证书，然后打开目标应用。修改 URL 后需刷新对应资源。证书固定的应用可能无法捕获。

旧版配置怎么处理？

本项目独立保存认证，不读取其他工具设置。请在本页重新配置青龙，并关闭旧抓包重写，避免重复推送。

数据保存在哪里？

应用配置保存在本机 QX 中。捕获值直接发送到青龙，不经过分发服务。请勿在 URL 中填写真实令牌，仅处理本人或已获授权的流量。
