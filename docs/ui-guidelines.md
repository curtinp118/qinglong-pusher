# 界面与交互规范

[返回开发文档](development.md)

## 信息结构

- 应用：只呈现列表、新建与搜索；三个及以上应用显示搜索，支持应用名称和变量名。
- 编辑：独立页面，一次只编辑一个应用；不把列表、说明和表单堆在同一页。
- 设置：集中放置运行状态、认证说明与常见问题；不重复展示 QX 入口安装步骤，PWA 添加到主屏幕独立保留。
- 预览：编辑页「预览 JS」使用只读生成接口，不新增或覆盖配置；面板标识草稿，允许返回修改或确认保存。`.conf` 与订阅地址单独折叠，预览不执行脚本。
- 保存：只有预览面板中的明确确认按钮可以保存，编辑页提交只预览。已保存且无更改时隐藏确认保存按钮。开发模式「确认保存到预览列表」仅保留在页面内存，不宣称保存到手机。
- 预览导航：左侧「返回编辑」与右侧关闭按钮均只关闭，不触发保存；去掉装饰性成功勾，未保存不能显示成功状态。统一使用编辑页的导航样式。
- 导入：只允许已保存版本或与已保存版本一致的预览。请求打开 QX 不等于客户端已成功导入。

## 视觉约束

- 仅面向 iPhone，内容宽度不超过 480px；检查 320、375、393、430px 布局。
- 使用中性浅灰背景、白色内容层、细分隔线；蓝色仅强调操作与选中状态。
- 不添加宣传型首屏、大幅装饰性标题、英文口号、无意义编号或重复状态卡片。
- 输入框正文至少 16px，主要触控区域至少 44px，适配底部与顶部安全区。
- 不依赖外部字体、图标 CDN 或网络图片；图标使用本地 SVG，跟随内容一起打包到 QX。
- 动效只用于页面和面板进入；尊重减少动态效果设置。

## 状态与安全

- 未保存退出时确认；放弃后保留上次保存版本。空白新配置不算更改。
- 删除应用、移除已填写规则需要确认；确认框默认聚焦取消。
- 保存期间禁用表单和离开操作；失败保留输入，不显示成功导入面板。
- 从预览面板保存时，错误在面板内展示并允许重试，不能隐藏到模态背后；请求完成前禁止关闭面板。
- 正则校验错误聚焦并标记对应输入；零启用规则保存须确认停用含义。
- 加载失败禁止新建，提供重试，不用空列表覆盖原配置。
- 预览明确标识，不显示实际导入按钮，不声称已保存到 QX。
- 使用原生 dialog 管理模态焦点、Escape 关闭与背景交互隔离；提示不包含敏感值。

## 浏览器回归清单

1. 空状态新建、请求头快捷选择、保存、关闭面板、返回列表。
2. 添加多个应用，验证独立订阅与按变量名搜索。
3. 编辑后返回，分别取消和确认放弃；验证已保存数据不变。
4. 删除确认取消不生效，确认仅删除当前应用，重新加载后其他应用仍保留。
5. URL 冲突、HTTP 保存失败时保留表单，保存按钮恢复可用。
6. 初始化失败禁止编辑，重试成功后恢复；窄屏无横向溢出。
7. 用真实 iPhone 检查软键盘、安全区、Safari 焦点与 QX 导入。浏览器模拟不替代这一步。

应用列表的每项底部并排显示「导入 QX」「删除」，与点击主体进入编辑分离。删除不再放在编辑页；必须确认，失败保留列表项并在列表展示错误。开发预览保留导入按钮但禁用，避免导入不存在于设备上的配置。异步操作结束后恢复列表按钮可用状态。

文案只保留操作标签、必要格式要求、状态与风险提示。不要添加“只编辑当前应用”“互不影响”等重复描述，不以解释性副标题填充留白。
